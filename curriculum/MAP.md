# Fundamentals map — mine to fill in

The abstraction stack: each layer is built from the one below. This is a **frame**, not a plan —
the columns are mine to fill as I go. A layer counts as understood when I can explain it *and*
have built something that proves it.

| # | Layer | The question it answers | Can I explain it? | Where I'm learning it | What I built to prove it |
|---|---|---|---|---|---|
| 1 | Electricity | What are voltage, current, resistance — and how do they relate? | ⬜ | | |
| 2 | Components | What does a resistor, capacitor, diode, transistor each do? | ⬜ | | |
| 3 | Gates | How does a transistor become a switch, and switches become AND / OR / NOT? | ⬜ | | |
| 4 | Combinational logic | How do gates add numbers or choose between inputs? | ⬜ | | |
| 5 | Sequential logic & memory | How does a circuit *remember* a bit? Why a clock? | ⬜ | | |
| 6 | Datapath | How do registers, an ALU and a bus move and transform data? | ⬜ | | |
| 7 | Control | How does an instruction tell the hardware what to do, step by step? | ⬜ | | |
| 8 | Software | Machine code → assembly → C → programs | ⬜ | | |

## Notes on gaps
- A simulator teaches layers 3–7 well but hides layers 1–2 (real electricity) and **timing**
  (on real hardware, signals take time and switches bounce). Those need a bench.
